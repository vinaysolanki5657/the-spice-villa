THE SPICE VILLA — DEMO WEBSITE

Files:
- index.html: complete responsive HTML/CSS/JavaScript website.

How to use on Android:
1. Download and extract the ZIP.
2. Open index.html in a browser to preview (internet is needed for the remote food photos).
3. Before using for a real client, replace demo restaurant details, menu/prices, phone, address, opening hours and WhatsApp number.
4. Publish using a static hosting service such as GitHub Pages or Netlify. Their current account and publishing requirements may change.

Important:
- The booking form currently opens WhatsApp with a pre-filled message; it does not store bookings or confirm availability.
- Replace 919876543210 in the JavaScript with the restaurant's real WhatsApp number, digits only including country code.
- Food photos load from Unsplash URLs and require an internet connection.
- Make sure you have permission to use client-provided logos, photos and content.
